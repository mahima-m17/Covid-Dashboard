# COVID-19 Data Analysis Dashboard

## Purpose

An interactive Power BI dashboard developed to analyze and visualize COVID-19 data. The project provides insights into COVID-19 cases, deaths, recoveries, and trends over time through interactive charts and visualizations.

## Tech Stack

- Power BI
- Power Query
- DAX
- Excel/CSV

## Features

- Interactive COVID-19 data dashboard
- Analysis of COVID-19 cases and trends over time
- Visualization of COVID-19 statistics by location
- Tracking of confirmed cases and deaths
- Interactive filters and slicers
- KPI cards for displaying key statistics
- Charts and graphs for identifying trends and patterns
- Data cleaning and transformation using Power Query
- DAX measures for calculating important metrics

## Key Questions Explored

- What is the total number of confirmed COVID-19 cases?
- How many COVID-19 deaths and recoveries were recorded?
- How did COVID-19 cases change over time?
- Which locations were most affected by COVID-19?
- Which locations recorded the highest number of deaths?
- How do confirmed cases, deaths, and recoveries compare across locations?
- What trends and patterns can be identified from the COVID-19 data?
